Startup School Finder 🧭

스타트업 창업을 꿈꾸는 학생들을 위해, “창업에 유리한 학교”를 정리하고 비교하는 데이터베이스 웹사이트. 검색/필터/정렬로 학교를 고르고, 입학 방식, 점수/요건, 학비(대략), 창업 리소스를 한눈에 봅니다.

검색 키워드
필터 국가/지역, 전공계열, 예산
정렬 학비, 선택도, 창업강도
확장 JSON으로 데이터 추가
⚠️ 안내: 아래 “점수/학비”는 샘플이며, 실제 운영용으로는 각 학교 공식 사이트 기준으로 업데이트해야 합니다. 이 페이지는 “구조 + 기능”을 완성해두고, 데이터는 너가 계속 채워 넣는 방식이에요.
